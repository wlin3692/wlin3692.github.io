# 流体光绘 / WebGL Fluid Simulation

这是小林个人网页中的中文互动版本，基于 Pavel Dobryakov 的 WebGL Fluid Simulation 改造。

- 鼠标与手机多点触控绘制流体
- 五套配色与可调画笔、旋涡、消散参数
- 三档画质、光晕、光束、暂停和清屏
- PNG 画面导出，可通过 HTTP 或直接打开 `index.html` 运行
