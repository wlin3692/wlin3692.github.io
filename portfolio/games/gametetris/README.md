俄罗斯方块 / JavaScript Tetris
=============================

这是小林个人网页中的响应式版本，基于 Jake Gordon 的 JavaScript Tetris 改造。

- 键盘与移动端按键控制
- 幽灵落点、硬降、等级加速和现代 7 袋随机
- 暂停、音效、深色模式和本地最高分
- 可通过 HTTP 或直接打开 `index.html` 运行

原项目
------

An HTML5 Tetris Game

 * [play the game](https://jakesgordon.com/games/tetris/)
 * read a [blog article](https://jakesgordon.com/writing/javascript-tetris/)
 * view the [source](https://github.com/jakesgordon/javascript-tetris)
