# 小林技能与项目路线图

这是基于 [Flowy](https://github.com/alyssaxuu/flowy) 改造的个人技能与项目路线图，作为小林个人网页的互动作品之一。

- 网络安全、前端交互、嵌入式开发、项目和目标五类路线节点
- 鼠标与触屏拖拽连接节点
- 一键添加、分支删除和初始路线恢复
- 节点详情、熟练度与作品跳转
- 使用结构化数据保存到浏览器本地存储
- 默认路线覆盖安全基础、网页工程、互动作品、AI/嵌入式项目与职业准备
- 桌面与移动端响应式界面

## 运行

通过静态服务器访问 `index.html`，或直接在浏览器中打开。
